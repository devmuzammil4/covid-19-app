# COVID-19 Global Tracker (Flutter)

A clean and interactive COVID-19 tracking application developed using Flutter. The app fetches real-world pandemic data via REST APIs, showcasing live global statistics alongside detailed country-by-country breakdowns. Built with proper asynchronous operations and user-friendly visual states.

## 🚀 Key Features
* **Smooth Visual States:** Displays a sleek circular progress indicator while fetching real-time data to guarantee a seamless user experience.
* **Global Overview Dashboard:** Presents worldwide cumulative statistics including total cases, active updates, recoveries, and mortality numbers upon startup.
* **Smart Search Filter:** Features a dedicated "Track Countries" dashboard where users can query any specific nation via a fast search bar.
* **Granular Country Analytics:** Clicking on any country reveals dedicated, detailed screens with precise data individual to that territory.

## 🛠️ Tech Stack & Architecture
* **Framework:** Flutter & Dart
* **Architecture:** Structured single-view logic with highly decoupled visual components.
* **API Integration:** Utilizes asynchronous HTTP operations for efficient data parsing and live updates.
* **UI/UX Design:** Implements explicit circular loading cues, customized list components, and modern search parameters.
